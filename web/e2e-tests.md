# E2E 测试规范

## 测试执行方式

使用浏览器 MCP 工具执行测试，参考以下命令格式。

## 测试用例库

### TC-001: 首页加载验证
```
操作: 访问 http://localhost:3001
验证:
  - 页面标题: "股票投资分析系统"
  - 导航菜单可见
  - 上证指数卡片显示
  - 热门股票表格显示
```

### TC-002: 个股分析表单
```
操作:
  1. 点击"个股分析"菜单
  2. 输入股票代码: 600519
  3. 选择风险偏好: 低风险
验证:
  - 页面跳转到 /stock
  - 输入框值正确
  - 风险偏好下拉可展开
```

### TC-003: 市场分析页面
```
操作:
  1. 点击"市场分析"菜单
验证:
  - 页面跳转到 /market
  - 关键词输入框存在
  - 风险偏好下拉存在
  - 开始分析按钮存在
```

### TC-004: 批量分析页面
```
操作:
  1. 点击"批量分析"菜单
验证:
  - 页面跳转到 /batch
  - 股票输入表格显示
  - 添加股票按钮可见
```

### TC-005: 实时行情页面
```
操作:
  1. 点击"实时行情"菜单
验证:
  - 页面跳转到 /quotes
  - 股票代码输入框存在
  - 查询按钮存在
```

### TC-006: 分析历史页面
```
操作:
  1. 点击"分析历史"菜单

```

### TC-007: API健康检查
```
操作: GET http://localhost:8000/api/v1/health
验证:
  - 状态码: 200
  - 返回: { status: "ok", version: "1.0.0" }
```

### TC-008: 股票行情查询
```
操作: GET http://localhost:8000/api/v1/quote/600519
验证:
  - 状态码: 200
  - 返回包含: price, change, percent
```

### TC-009: 并发压力测试
```
场景: 50个并发健康检查请求
验证:
  - 成功率: 100%

```

### TC-010: 表单验证

## Monkey 测试随机场景

### 导航区域
- 快速连续点击5个不同菜单
- 多次点击同一菜单

### 表单区域
- 输入特殊字符: `!@#$%^&*()`
- 输入超长字符串: 1000+字符
- 快速多次点击提交按钮

### 全局操作
- 浏览器前进/后退
- 页面缩放 (50%, 150%)
- 快速滚动页面

## 回归测试命令

```bash
# 启动服务
cd stocks-optimization && python run_api.py &
cd web && npm run dev &

# 执行测试序列
1. TC-001: 打开首页
2. TC-002: 测试个股分析
3. TC-003: 测试市场分析
4. TC-004: 测试批量分析
5. TC-007: 验证API
```
